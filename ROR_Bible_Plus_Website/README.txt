ROR Bible+ Premium Bible Reader: website (responsive, desktop and mobile)
=========================================================================

Open index.html in any browser to view the site. For the best results
(fonts and video), serve the folder from a web server.

FOLDERS
  index.html ........ Home
  features.html ..... Features (all 10)
  pricing.html ...... Pricing (Free, Premium, Pro, Max)
  download.html ..... Download and Support (with contact form)
  web.html .......... ROR Bible+ Web (Bible Online and Bible Lite PWA)
  mobile.html ....... ROR Bible+ Mobile (Android and iOS)
  desktop.html ...... ROR Bible+ Desktop (MacOS, Windows and Linux)
  voice.html ........ ROR Bible+ Voice (Amazon Alexa and Google Home)
  css/styles.css .... All styles, including the responsive (mobile) rules
  js/main.js ........ Sticky header, Products menu, mobile menu,
                      pricing Monthly/Yearly switch, TV promo player
  images/ ........... All images used on the site
  fonts/ ............ Montserrat (self-hosted, SIL Open Font License: fonts/OFL.txt)
  media/ ............ Put the TV promo video here: ror-bible-plus-tv-promo.mp4
